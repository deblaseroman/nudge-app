## Deviations from the plan

- **R3 tightened.** The plan said Unscheduled = "no plan day"; the first
  eval run showed a task owed today with no plan day in both Today and
  Unscheduled, which is overlap without information. Unscheduled is now
  "no plan day AND not on today's list"; the spec text, `DESIGN.md` and
  `CLAUDE.md` say so.
- **One new column.** `planDayIsAuto` was not in the plan. Without it,
  Clear plan / replan / displacement could not tell a day the planner wrote
  from a day the user chose, and would either strip the user's day or leave
  planner-pulled tasks stranded on Today. Property-level default; no
  schema list touched (same `@Model`).
- **A task pushed off today's timeline** (reflow, no room) keeps today as
  its plan day instead of going to Unscheduled: it is still today's work,
  just without a slot.
- **The import backfill** now releases any placement on a different day
  than the owed day, not only auto ones (I1). It has already run once on
  Roman's phone (stamped), so this is inert there.
