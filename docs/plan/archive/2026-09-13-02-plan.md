# Plan — 2026-09-13-02 — The Nudge calendar (as approved in chat)

**Status:** APPROVED — Roman, Sep 13 2026, in chat ("go on the calendar
view"), design settled across the preceding conversation.
**Cycle ID:** 2026-09-13-02

## Design constraints (Roman's, verbatim where quoted)

- The heart of the app is "the widget, notifications, and the simplicity
  of the tasks tab" — the calendar is a rarely-visited glance for "what's
  coming past this week", never a calendar-app competitor.
- Not interactive beyond: tap an item → "the window slides up to change
  the date and time, just like we already have" (the existing editor).
- "All this is doing is providing a visualization of that, not making
  another thing the AI needs to read" — pure display, downstream of the
  store.

## Items

1. `NudgeTask.scheduledDay` — the day-membership rule hoisted from
   TasksTabView to the model so lenses + calendar read one
   implementation.
2. **Intent-aware editor**: shared `TaskEditorSheet.apply(draft:to:
   modelContext:)` replaces the inline write logic; for an intent-only
   task the date picker (labeled "Planned") moves `intendedDate` + the
   placement when a time is chosen, never minting a deadline; events
   ("Time") and deadline tasks ("Due") unchanged; draft seeds from
   intent+placement. Precondition for the calendar's tap-to-edit being
   safe.
3. **Month view** at the top of the Calendar tab: month navigation +
   Today jump, weekday grid, per-day dots (event=stone, scheduled=blue,
   due=amber — deadline tasks INCLUDED here though excluded from day
   lenses: an orientational surface that omitted the essay due Friday
   would read as broken), legend, selected-day item list, tap →
   `TaskEditorSheet` via the shared apply.

## Out of scope

- Drag/drop, week grids, writing to Apple Calendar, widening the 21-day
  import window (free, deliberate product choice to keep modest).
- Floater-given-a-date still mints a deadline in the editor — the
  convert-kind default is the standing deferred question.

## Evidence

- Both schemes build; device look: dots match items, tapping an intent
  task and moving its day changes `intendedDate` (no countdown appears),
  moving an event changes its time, a deadline task keeps its countdown.
