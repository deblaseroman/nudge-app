Map index.mmd

Read it top to bottom. A capture inserts task rows. Task rows feed the copy writer, a focus session and the notification arbiter. All of it runs in the four targets and two stores at the bottom. Cylinders are stored state. Arrows inside a region are explained on that region's page.

The six sets

Each link is the artifact page named on the first line of the set's .mmd file. Files are in docs/diagrams.

SetWhat it drawsFiles
Capture sequence The brain-dump capture path. HomeTabView sends the message, ClaudeService posts it to api.anthropic.com, CaptureWriter inserts NudgeTask rows. capture-sequence.mmd and 11 stages: 1-send, 2-request, 3-rows, 4-session, 5-widget, 6-signals, 7-commitments, 8-copy, 9-plans, 10-consent, 11-arbiter
Task lifecycle Every state of a NudgeTask row and every function that moves it: creation, planners, placement, rollover, generated rows, completion, and the readers that decide a list or screen. task-lifecycle.mmd and 8 close-ups: overview, creation, creation-auto, planner, placement, rollover, generated, completion
Copy sequence Where a scheduled nudge's text comes from, where it is kept, and how it is attached to the request. copy-sequence.mmd and 9 stages: 1-triggers, 2-requests, 3-write, 4-schedule, 5-lookup, 6-fill, 7-snooze, 8-fixed, 9-screentime
Session lifecycle The focus session behind the Live Activity as a state machine, through suspension, process death and relaunch. session-lifecycle.mmd and 5 close-ups: activity, start, end, sync, widget
Notification flow Every place a notification request is handed to iOS, traced backward: triggers, the arbiter run, delivery and taps, the Screen Time extension. notification-flow.mmd and 10 close-ups: overview, arbiter, delivery, outcomes, screentime, copy, launch, triggers, widget, permission
System context The four build targets, every persistent store, and the two network services. system-context.mmd and 4 close-ups: network, widget, screentime, notifications

The map leaves out three system-context boxes to stay within five per row: Secrets.plist, the DEBUG Documents files and the iCal feed host.
