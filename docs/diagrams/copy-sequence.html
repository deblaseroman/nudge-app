Exists but has no effect

On the text path. None of these is a step on the main path, so none is drawn.

  1. validBody's fireDate parameter is passed by resolvedBody and never read. No check compares the deadline with the fire date; tense is handled later by {due}.
  2. tier(for:fireDate:)'s fireDate parameter is never read. The tier, and so the title's prefix and casing, is measured from the moment the candidate is built, not from when it fires.
  3. NudgeCopyStore.clear() is called by nothing. The cache is only ever replaced or left to age out.
  4. The empty-request guard in generateIfNeeded, and the one in generateNudgeCopy, cannot be taken: buildRequests always appends the idle, comeBack and goalLapse items.
  5. CachedNudgeCopy.taskTitle is stored with every entry and read only by the DEBUG dump.
  6. GeneratedCopyJSON is a private Codable struct nothing decodes into; decodeGeneratedCopy reads rows with JSONSerialization.
  7. category.getAhead is registered with three button labels, and no builder puts it on a request.
  8. LimitDecision.silent has an empty title and a reason for a body; neither is posted. The reason reaches only the breadcrumb list.
  9. NudgeCopyStore.debugDump, the swap printout in resolvedBody and the -nudge-regenerate-copy argument exist in DEBUG builds only.

Scope

Read from source at ede6774: Swift, plist, entitlements and the Xcode project file. No documentation files were read.

  • Targets (Nudge.xcodeproj/project.pbxproj): Nudge, NudgeWidgetExtension, NudgeActivityMonitor, NudgeActivityReport. Notification content is built in Nudge (three sites) and NudgeActivityMonitor (one). Models/DistractionSettings.swift is compiled into the extension targets through membership exceptions, which is how LimitDecider runs outside the app.
  • Entitlements: all four targets carry the App Group group.com.deblaser.nudge, where the cache lives. No push entitlement exists, so every notification is local.
  • Info.plist: no notification text. NudgeActivityMonitor/Info.plist declares the com.apple.deviceactivity.monitor-extension point that lets iOS run stage 9.
  • Not notifications: the widget and the Live Activity draw their own views; the widget's CompleteTaskIntent only removes pending requests.
  • Working tree: Nudge/Views/Components/TodayTimelineView.swift has uncommitted changes. It is not on this path and is not linked from this page.
