How the Calendar Reaches Nudge

Three doors in, one store, and every reader that looks ahead from it, measured in the app's own days. The state of the working tree on the morning of September 16, 2026; section 4 records what the afternoon's cycle changed.

1.0Three doors in, one store

Every calendar item becomes a NudgeTask row with source = "calendar" (or "screenshot"). The import itself is deterministic and offline; the only door that spends tokens is the screenshot, because a picture has no structure to parse. What differs between the doors is how far they reach and whether they ever reach again.

2.0Who looks ahead from the store, and how far

"Three weeks" is the import edge, not a reading window. Nothing in the app reads three weeks of calendar as a unit and plans from it. Each reader below has its own reach, and each is drawn on the same day axis so the reaches can be compared. Green is arithmetic; blue is an AI call; the dashed bar is text that mentions dates without reading the calendar at all.

3.0Where an exam becomes study time, and where a trip becomes nothing

The one "plan ahead" mechanism that exists is the exam-prep sweep. It is keyword-gated at import: a title that looks like an exam gets category = "exam", and the sweep only reads that category. A trip is an event keyword too, but it lands as an informational event with no category the sweep reads, so it produces no preparation of any kind.

4.0What this shape cannot do

Each entry names the seam, so the companion map can be read as a set of answers rather than a wish list.
